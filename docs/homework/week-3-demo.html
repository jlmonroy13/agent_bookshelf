Same suite, same graders, only the orchestrator model changes.

On the three cases that finished for both models, Sonnet scored 0.98 and Opus 0.97, and Sonnet cost 0.19 USD per run against 0.29 USD.

What the eval caught, and the promotion

The skill scored the same with and without it on most cases. The tasks were too easy.

But two cases failed in both arms: when I asked for a new column or a new npm package, the agent edited schema.sql and package.json without asking.

The rule was already in the skill, in one buried sentence. I promoted it to an explicit Step 0: approval check, before reading or editing anything.

The schema case went from 0.33 to 0.56. The dependency case did not move, probably because the skill is about endpoints and never loads for that request. That is a lead, not a conclusion.

What the eval cost me

The eval cost about 46 USD at list price. Around 25 USD of that went into batches I threw away.

I ran the full suite before checking one case end to end with the final permissions, and my tester agent was blocked. I also changed a grader between batches.

Next time: one case with the final setup, freeze the graders, then one run per case, and repeat only where the signal is unclear.

An eval is also a spend. Measuring quality has to be designed as carefully as the thing it measures.

Before you present

Likely questions

Is Sonnet really as good as Opus?

Not proven. Nine runs per side gives roughly plus or minus 18 points at this scale. I can say there was no visible gap and that Sonnet was cheaper.

Why did the skill add nothing?

Sonnet already does these tasks without it, so the Δ is near zero. The useful finding is the two guardrail cases that fail either way.

Why trust code graders over a judge?

They are fast and repeatable. I only used a Haiku judge on four short-answer cases and did not calibrate it against a human.

Did the eval touch your real repo?

No, git status stayed clean. But in one trace the tester ran commands against the real path and deleted files in /tmp, so the sandbox was not fully sealed.

What would you cut?

Seven of the ten group B cases and the Opus repeats. Three well-chosen cases gave the same answer for a fraction of the cost.
